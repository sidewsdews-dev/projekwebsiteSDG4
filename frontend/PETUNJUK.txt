PETUNJUK INSTALASI & PENGGUNAAN PORTAL AKADEMIK SATU PINTU
=====================================================================

1. PERSIAPAN DATABASE
   - Buka phpMyAdmin (http://localhost/phpmyadmin)
   - Import file `frontend/dataprojek.sql` untuk membuat database `dataprojek` & seluruh tabel.
   - Import file `frontend/seed_demo.sql` untuk mengisi data contoh (guru, siswa, admin, jadwal, tugas, berita, event).

2. KONFIGURASI KONEKSI
   - Cek file `frontend/koneksi.php`:
     $db_host = "localhost";
     $db_user = "root";
     $db_pass = "";
     $db_nama = "dataprojek";
   - Pastikan folder `frontend` diletakkan di dalam `htdocs` (XAMPP) atau `/var/www/html` (LAMPP).

4. RINGKASAN FITUR TERINTEGRASI
   - Portal Satu Pintu (`index.php`, `login.php`, `daftar.php`):
     * Halaman depan menampilkan info peran, berita terbit, dan agenda event.
     * Registrasi akun baru untuk Siswa maupun Guru (otomatis berstatus menunggu sampai disetujui Admin).
   - Dashboard Admin (`dashboard-admin.php`, `admin_aksi.php`, `akun_aksi.php`):
     * Persetujuan / penolakan pendaftaran akun baru (dan penetapan kelas siswa).
     * CRUD lengkap Data Guru, Data Siswa, Akun Admin, Kelas, Mata Pelajaran, Pengampu, Jadwal Pelajaran, serta Konten Website (Berita & Event).
   - Dashboard Guru (`dashboard-guru.php`, `guru_aksi.php`):
     * Melihat jadwal mengajar harian & mingguan.
     * Unggah & hapus materi pembelajaran.
     * Buat tugas (dengan lampiran soal opsional) & beri nilai pada pengumpulan tugas siswa.
     * Input nilai Harian, UTS, dan UAS per kelas/mapel.
     * Input & rekap absensi kelas per tanggal.
   - Dashboard Siswa (`dashboard-siswa.php`, `kumpul_tugas.php`, `download.php`):
     * Melihat identitas lengkap, wali kelas, jadwal pelajaran, dan materi.
     * Mengumpulkan / mengganti berkas tugas sebelum dinilai.
     * Melihat daftar nilai (Harian, UTS, UAS, Rata-rata) dan rekap serta riwayat absensi.
